# Rom Cartech – Website

Next.js 15 + Tailwind CSS 4. Startbild mit Lack-Konfigurator (Farbe per Klick umschaltbar).

## Vor dem Livegang
Alle Firmendaten und Texte stehen in **`lib/site.ts`**.
Noch offen: Firmierung/Inhaber (`[eckige Klammern]`), Öffnungszeiten (`hours`),
Facebook-/Instagram-Links, Impressum- und Datenschutztext (`app/impressum`, `app/datenschutz`).

## Entwickeln
npm install
npm run dev
